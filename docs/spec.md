# 個人工作室預約系統規格書

## 系統概述

提供個人工作室業主管理可預約時段，以及讓顧客線上預約服務的系統。預約確認後，系統透過 LINE 通知雙方。

---

## 角色

| 角色 | 說明 |
|------|------|
| 業主 | 管理開放時段、確認或拒絕預約 |
| 顧客 | 瀏覽開放時段、提交預約申請 |

---

## 主要流程

```
業主開放時段
     ↓
顧客選擇時段並填寫預約資料
     ↓
系統建立「待確認」預約，通知業主
     ↓
業主確認或拒絕預約
     ↓
系統傳送 LINE 訊息通知顧客結果
```

---

## 功能模組

### 1. 業主後台

- 登入 / 登出
- 開放可預約時段（單次或週期性）
- 關閉 / 修改已開放的時段
- 查看所有預約申請（待確認 / 已確認 / 已拒絕）
- 確認或拒絕預約

### 2. 顧客預約頁面

- 瀏覽可預約的時段（月曆或列表視圖）
- 選擇時段並填寫預約資料（姓名、聯絡方式、備註）
- LINE 登入（取得 userId，用於後續通知）
- 查看自己的預約狀態

### 3. 通知系統（LINE Messaging API）

- 顧客提交預約後，通知業主有新預約
- 業主確認後，通知顧客預約成功
- 業主拒絕後，通知顧客預約未成功（可附原因）

---

## 預約狀態

```
pending（待確認）→ confirmed（已確認）
                 → rejected（已拒絕）
```

---

## 資料模型（初稿）

### 時段（Slot）

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | UUID | 主鍵 |
| start_at | DateTime | 開始時間 |
| end_at | DateTime | 結束時間 |
| is_available | Boolean | 是否開放預約 |

### 預約（Reservation）

| 欄位 | 型別 | 說明 |
|------|------|------|
| id | UUID | 主鍵 |
| slot_id | UUID | 對應時段 |
| customer_name | String | 顧客姓名 |
| customer_phone | String | 聯絡電話 |
| customer_line_id | String | LINE userId（用於推播） |
| note | Text | 備註 |
| status | Enum | pending / confirmed / rejected |
| created_at | DateTime | 建立時間 |

---

## LINE 整合方式

- 使用 **LINE Messaging API** + **LIFF（LINE Front-end Framework）**
- 顧客需先加業主官方帳號為好友，才能收到推播通知
- 顧客在預約頁面透過 LIFF 完成 LINE 登入，系統取得 `userId` 存入預約資料
- 預約狀態變更時，後端呼叫 Push Message API 發送通知
